# React + TypeScript + Vite

## UI libraries

- [Chakra UI](https://chakra-ui.com/) — component library.
- [next-themes](https://github.com/pacocoursey/next-themes) — color mode (light/dark) switching.
- [Zustand](https://github.com/pmndrs/zustand) — client-side state management.

## Husky

Git hooks are managed with [Husky](https://typicode.github.io/husky/). Running `pnpm install` triggers the `prepare` script, which sets up the hooks in `.husky/`.

- `pre-commit` — runs `pnpm lint`
